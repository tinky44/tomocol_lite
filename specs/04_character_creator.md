# Character Creator

## Direction

このゲームは「長身少女を固定キャラクターとして配置する」ものではない。

住人を作るゲームであり、その作成幅の中に、かなり背の高い少女や、背の低い住人、がっしりした住人、頭が大きめの住人などを自然に含められるようにする。

狙いは「トモコレ風の生活箱庭だが、身長と体型の上限がもっと広い」方向である。

## Editable Axes

初期の体型編集:

- 身長
- 頭の大きさ
- 胴の長さ
- 脚の長さ
- 肩幅/体の幅
- 肌色
- 髪色
- 服色

初期の顔編集:

- 目の大きさ
- 目の間隔
- 目の高さ
- 口の幅
- 口の高さ
- 髪型カテゴリ

顔パーツ編集の楽しさは重要だが、特定作品のパーツ形状やUIをそのまま再現しない。プリミティブ形状から始め、ゲーム独自の記号的な顔に育てる。

## Height Range

身長は広く取る。

- 初期下限: 1.35m
- 平均基準: 1.60m
- 初期上限: 2.60m

上限は現実的な平均から大きく外れるが、ファンタジーとしてではなく「生活空間とのズレが強く出る作成幅」として扱う。

## Creator UX

最初は本格的なキャラメイク画面を作らなくてよい。プロトタイプでは、選択中の住人に対してキー入力で数値を変え、部屋内でスケール差を確認できれば十分。

将来の画面構成:

- 左側: 住人プレビュー
- 右側: 顔、体型、服のタブ
- 下部: ランダム、複製、保存
- 背景: 普通サイズのドア、椅子、机を置いたスケール確認空間

## Saved Profile

住人データは、最低限以下を持つ。

```text
name
height
head_ratio
torso_ratio
shoulder_scale
skin_color
hair_color
cloth_color
eye_spacing
eye_height
eye_size
mouth_width
mouth_y
hair_style
personality
relationships
```
