# Scale Language

## Units

Godot の 1.0 ユニットを 1m として扱う。

基準値:

- 平均身長住人: 1.60m
- 初期作成下限: 1.35m
- 初期作成上限: 2.60m
- ドア高さ: 2.00m
- 天井高さ: 2.35m から 2.45m
- 机高さ: 0.72m
- 椅子座面: 0.43m
- キッチン/洗面台: 0.85m から 0.90m

## Deformed Character Ratio

リアル寄りではなく、頭が大きめのデフォルメ体型を使う。

平均住人:

- 全高 1.60
- 頭 0.42
- 胴 0.58
- 脚 0.60

高身長住人の例:

- 全高 2.20 から 2.60
- 頭 0.48 から 0.58
- 胴 0.72
- 脚 1.00 以上

「脚と胴が少し長いが、頭もデフォルメされている」方向にする。リアルなモデルの難しさを避けつつ、画面上の高さ差ははっきり出す。

## Visual Comparisons

身長差は、次の比較対象で見せる。

- ドア枠
- 天井と照明
- 椅子と机
- ベッドの長さ
- 棚の段
- 他住人との並び
- カメラのフレーミング

## Camera

初期は生活箱庭に近い固定カメラ。

- 斜め正面から部屋を覗く
- Orthographic または弱い Perspective
- 部屋全体と身長差が同時に見える
- キャラクターの足元とドア上端が同じ画面に入る

## Animation Priority

凝ったアニメーションより、姿勢差を優先する。

初期優先度:

1. 立ち姿
2. 歩行
3. 頭を少し下げる
4. 座る
5. 見下ろす/見上げる

姿勢が伝われば、手足の細かなアニメーションは後回しでよい。
