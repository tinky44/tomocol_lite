# トモコレライト 遊び方

2026-05-12 時点のプロトタイプ操作メモです。

## 起動

PowerShell から Godot を起動します。

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\run_godot.ps1
```

読み込み確認だけなら以下です。

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\run_godot.ps1 -Headless -Quit
```

## 基本操作

- `W/A/S/D` または `矢印キー`: メインキャラを移動
- `E` / `Enter` / `Space`: 近くの対象にアクション
- `クリック` または `F`: キャラメイク画面に入る
- `J/L`: カメラ回転
- `I/K`: カメラ高さ変更
- `-` / `=`: ズーム変更
- `Home`: カメラを初期位置に戻す

現在はメインキャラ 1 人を中心に見る構成です。`Q` や `Tab` で他住人へ切り替える操作は使いません。

## 家に入る・出る

島で家の玄関マット付近に立って `E` を押すと、家の中に入ります。

部屋ではドア付近に立って `E` を押すと、島へ戻ります。部屋の家具付近で `E` を押すと、棚、椅子、机、ベッド、ドアに応じた短い反応が出ます。

## キャラメイク

キャラをクリックするか、`F` を押すと、黄色い背景のキャラメイク画面に切り替わります。

キャラメイク画面では、左側のメニューをクリックして編集します。

- 名前欄: キャラ名を編集
- `体型` / `顔` / `髪` / `服`: 編集カテゴリを選ぶ
- 項目ボタン: 変えたい項目を選ぶ
- `-` / `+`: 値や種類を切り替える
- `完了`: 島や部屋に戻る

編集カテゴリは以下です。

1. 体型
2. 顔
3. 髪
4. 服

## 服編集のやり方

1. キャラをクリックしてキャラメイク画面に入る。
2. 左側メニューの `服` をクリックする。
3. `服の種類`、`服の色`、`肌の色`、`靴の色` から変えたい項目をクリックする。
4. `-` / `+` で見た目を切り替える。
5. `完了` で戻る。

服カテゴリの項目:

- 服の種類
- 服の色
- 肌の色
- 靴の色

服の種類は `普段着`、`スカート服`、`きちんとした服`、`エプロン`、`部屋着` を切り替えます。

靴は今のところ簡易的な足元パーツです。`靴の色` を選んで `-` / `+` を押すと靴色が変わります。

## 贈り物で着替える

編集モードとは別に、贈り物から服を渡して着替えることもできます。

- `T`: 贈り物カテゴリを切り替える
- `U`: カテゴリ内のアイテムを切り替える
- `Y`: 選んだ贈り物を渡す

左上の `贈り物:` 表示が `服 / ...` になっている状態で `Y` を押すと、その服に着替えます。

## 相談とイベント

左上の `相談:` に内容が出ているときは、`E` で解決できます。服がほしい相談の場合は、服を渡す、または相談解決で着替えにつながります。

現在の交流イベントはまだ簡易版です。今後、友人化、会話ズーム、ハート系の吹き出し、関係性イベントを増やしていく予定です。
