# tall_life_simulator 参考仕様メモ

このメモは、過去作品の別リポジトリ `tall_life_simulator` を今後 `tomocol_lite` の参考にするときの入口です。丸ごとの移植ではなく、設計判断や分割方針を再利用するためにまとめます。

## 参照したい設計

- キャラクター描画は、統括、身体、服、髪、姿勢計算に分かれている。
- 表示方向ごとに正面/側面の描画処理を分けている。
- `DrawContext` 相当の共有コンテキストに、体格、色、服種、髪型、向き、視線、姿勢を集めてから各描画層へ渡している。
- 身長だけでなく、頭身、肩幅、脚比率、姿勢、ストレス値が見た目へ反映される。
- 髪型と服は、種類と色を分けて持つ。追加時は既存の描画レイヤーに小さく足せる構造になっている。
- キャラ作成画面では、スライダー/選択肢で身長、頭身、脚比率、服、髪などを調整する。

## 主なファイル

- `godot-project/scripts/CharacterDrawer.gd`
  - 描画の統括。向きや外見データを集め、正面/側面の描画へ委譲する。
- `godot-project/scripts/CharacterBodyDrawer.gd`
  - 身体パーツの描画。
- `godot-project/scripts/CharacterClothingDrawer.gd`
  - 服、靴、帽子、バッグなどの描画。
- `godot-project/scripts/CharacterHairDrawer.gd`
  - 髪型ごとの描画。
- `godot-project/scripts/CharacterPoseCalculator.gd`
  - 身長や姿勢から、頭、胴、腕、脚の位置や角度を計算する。
- `godot-project/scripts/CharacterCreatorScene.gd`
  - キャラ作成 UI。身長、頭身、脚比率、服、髪などの入力例として有用。
- `specs/character_drawing_system.md`
  - 描画分割とレイヤー順の仕様メモ。
- `specs/clothing_and_hair_logic.md`
  - 衣装と髪の描画規則。

## tomocol_lite へ持ち込む方針

- 今作は 3D プリミティブの生活箱庭なので、過去作の 2D Canvas 描画は直接移植しない。
- 代わりに、キャラクター描画を `ResidentAvatar.gd` のような専用スクリプトへ切り出す。
- `Main.gd` は、島、部屋、入力、保存、住人 AI、イベントを管理する。
- 髪型、服、顔パーツは、まず少数のプリミティブ形状で実装する。
- 将来、正面/側面/背面や姿勢差が増えたら、過去作と同じように描画層をさらに分割する。

## 今作で優先して再利用する考え方

1. キャラ描画をメインシーンから分ける。
2. 外見データは住人プロフィールに保存する。
3. 髪型/服/顔は種類と数値を分けて持つ。
4. 身長差は、脚だけを伸ばすのではなく、頭、胴、脚の比率で自然に見せる。
5. 身長や姿勢による生活上の反応を、会話、家具、ドア、棚、ベッドへ接続する。

## 注意点

- 過去作は長身少女の成長シミュレーション寄りで、今作は住人作成幅の広い生活箱庭。
- 過去作固有の物語、年齢進行、成長演出は、そのまま持ち込まない。
- 今作では「普通体型向けの日常空間」が先にあり、その中で体型差が見える設計を優先する。
